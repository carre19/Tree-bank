# 🌳 Tree Bank — Homebanking Frontend

Sistema de homebanking desarrollado en React + Vite como proyecto de **Practicas Profesionalizantes I**.

## Acceso demo (sin backend)

| Campo | Valor |
|-------|-------|
| DNI | `00000000` |
| Contraseña | `demo1234` |

> El modo demo muestra datos ficticios. Para usar datos reales necesitas tener el backend corriendo en `localhost:3001`.

## Pantallas

- **Login** — autenticacion con DNI y contraseña
- **Dashboard** — saldo, CBU, alias y acciones rapidas
- **Transferencias** — enviar dinero a cualquier CBU o alias
- **Depositos** — registrar ingreso de efectivo
- **Historial** — todos los movimientos con filtros
- **Perfil** — editar datos personales y cambiar contraseña

## Tecnologias

- React 18 + Vite
- React Router DOM v6
- Axios
- CSS inline + media queries responsive

## Instalacion

```bash
npm install
npm run dev
```

Abrir en el navegador: `http://localhost:5173`
